## LEGB 

**LEGB** stands for **Local, Enclosing, Global,** and **Built-In**.
- **Enclosing** names are known as **nonlocal** names - to edit these names, you have to use **nonlocal** within the scope
- To edit **global** names within a scope, you have to use **global** within that scope
